# ToPu_AnimationStudio

**Blenderのアニメーション制作に使うツールを、3つの専用エディターと共通のTPASパネルにまとめた統合アドオンです。**

キーフレームの数式編集、イージング、リグ操作、ポーズ管理、モーションパス、オニオンスキン、ドライバー、揺れもの、時間・FPSの調整まで、制作工程に合わせて組み合わせて使用できます。

| 項目 | 内容 |
| --- | --- |
| バージョン | **0.1.85** |
| アドオン名 | `ToPu_AnimationStudio` |
| 統合・開発 | http4211 |
| 対象Blender | **5.1以降**（アドオンの最低バージョン指定は5.1.0） |
| 表示言語 | 日本語／英語／Blenderの言語に合わせる自動切り替え |
| 主な操作場所 | Animation Studio、Curve Editor、Rig Picker、Nパネルの **TPAS** タブ、各エディターのヘッダー |
| ライセンス | GPL-3.0-or-later。統合元・同梱素材の著作権表示とライセンスを保持 |

このREADMEは **v0.1.85の実装**に合わせた機能・操作ガイドです。統合元の単体版とはUI、保存先、操作方法が異なる部分があります。以降では本アドオンを **TPAS** と表記します。

<a id="overview"></a>
## 主な特徴

- **Animation Studio**：再生、入力式、相対編集、自動キー入力、ループ、表示フィルター、フレーム設定、変換操作などを集約。
- **Curve Editor**：ベジェ曲線やダイナミック補間を編集し、選択キーフレームへ適用。
- **Rig Picker**：シェイプ、画像、スライダー、2D移動ボタンで、ボーン選択や登録プロパティを操作。
- **柔軟な表示**：専用ウィンドウ、専用エリア、オーバーレイを用途に応じて切り替え。
- **共通UI**：GPU描画、画面サイズに合わせたUI倍率調整、ホバーヒント、日本語・英語切り替えを共通化。
- **TPASタブ**：ポーズライブラリ、ドライバー、揺れものなどのNパネルをまとめて配置。
- **プロジェクト内保存**：リグピッカーのレイアウトを.blendに保存し、ファイルごとの設定として管理。

<a id="installation"></a>
## インストール

1. `ToPu_AnimationStudio_v0.1.85.zip` を用意します。
2. 統合元の単体アドオンを使用している場合は、先に無効化します。
3. Blenderの **編集 → プリファレンス → アドオン → ディスクからインストール** でZIPを選択します。
4. **ToPu_AnimationStudio** を有効にします。
5. 必要に応じて、プリファレンスの **UI表示** と **専用ウィンドウ** を設定します。

ZIPは展開せずにインストールできます。単体版と統合版は同じオペレーター名などを使用するため、同時に有効化できないものがあります。競合が検出された場合は、メッセージに表示された単体版を無効にしてから有効化してください。

更新時は.blendを保存し、TPASの専用画面を閉じてから入れ替えてください。旧版の処理が残る場合はBlenderを再起動してください。単体版のプリファレンスすべてが自動移行されるわけではありません。

### 最初に使うには

- **キーを編集したい**：グラフエディターで対象キーを選択し、ヘッダーからAnimation StudioまたはCurve Editorを開きます。
- **リグを操作したい**：アーマチュアを選択してRig Pickerを開き、右クリックからリグセットまたはボタンを作成します。
- **ポーズ・ドライバー・揺れものを設定したい**：3Dビューポートで `N` を押し、**TPAS** タブを開きます。

<a id="editors"></a>
## 3つの専用エディターと表示方法

| エディター | 主な用途 | ヘッダーの起動アイコン |
| --- | --- | --- |
| Animation Studio | アニメーション編集の総合操作 | `PROJECT` |
| Curve Editor | イージング曲線の作成・適用 | `NORMALIZE_FCURVES` |
| Rig Picker | リグ選択・数値操作・ボタン配置 | `OUTLINER_DATA_ARMATURE` |

アイコン名はBlender内部の識別名です。実際のUIではアイコンとして表示されます。起動ボタンは3Dビューポートやアニメーション系エディターのヘッダーに表示され、表示中のツールはハイライトされます。表示場所はプリファレンスで変更できます。

### 表示モード

| モード | 使い方 |
| --- | --- |
| 専用ウィンドウ | ツールを独立したBlenderウィンドウで開きます。別画面で常時操作する用途に向きます。 |
| 専用エリア | Blenderのエリアをそのツールの画面として使います。エディター種類の切り替えから選択できます。 |
| オーバーレイ | 既存エリアの上にツールを重ねて表示します。対応ヘッダーの起動ボタンを **Shift＋クリック** して呼び出せます。 |

同じツールのメイン表示は切り替えて使用します。専用エリアから専用ウィンドウへ移った場合、元エリアはツールのエリアとして残り、**こちらをメインにする** から表示を戻せます。Studio、Curve、Pickerは別々のツールとして管理されます。

オーバーレイは上部の移動用帯をドラッグして移動し、四隅のハンドルでサイズを変更できます。透明度も調整できます。Rig Pickerでは、以前のオーバーレイ位置・サイズがある場合、それを初期設定より優先します。

専用画面のUI倍率は画面サイズに合わせて調整されます。ボタンにカーソルを合わせると操作ヒントが表示され、ShiftやCtrlなどの修飾キーは色を分けて案内されます。

<a id="animation-studio"></a>
## Animation Studio

日常的なアニメーション編集を、アイコン中心のコンパクトな画面にまとめています。

| 操作グループ | 内容 |
| --- | --- |
| 再生 | 開始／終了へ移動、前後のキーへ移動、逆再生、再生、停止 |
| 自動キー入力 | OFFは○、ONは●で表示。詳細設定にもアクセス可能 |
| ループ | カーブへループを適用、繰り返し方法を設定、Alt＋クリックで削除 |
| 相対編集 | 有効／無効と、選択キーのみを対象にする設定 |
| 入力式 | フレーム／値の対象切り替え、数式の直接入力、適用、関数一覧、お気に入り |
| グラフ表示 | 移動／回転／スケール、X／Y／Z、選択のみの絞り込み |
| フレーム設定 | プレビュー範囲、開始・終了フレーム、FPSプリセット／カスタム値、変換・決定 |
| 変換ツール | コピー／貼り付け、ピン、一時ピボット、カーソル操作、親切替 |
| 補助操作 | ポーズ左右反転、オニオンスキン、モーションパスとピン止め、マーカー変更 |
| 登録プロパティ | 登録した値の直接編集と、登録した選択の呼び出し |

自動キー入力・相対編集の状態は、該当する操作枠の背景色でも確認できます。登録プロパティの枠は登録項目がある場合に表示されます。

ポーズライブラリ、ドライバー作成、揺れもの設定などの詳細なパネルは、**TPASのNパネル**を使用します。

### ポーズの左右反転

アーマチュアのポーズに対し、同じアイコンを修飾キーで使い分けます。

| 操作 | 動作 |
| --- | --- |
| クリック | ポーズ全体を左右反転 |
| Shift＋クリック | 反対側のポーズを、選択している側へ取得 |
| Ctrl＋クリック | 選択している側のポーズを、反対側へ適用 |
| Shift＋Ctrl＋クリック | 反対側から選択側へ取得 |

左右対応するボーン名と、リグの構成に応じて動作します。リグ固有の制約や左右非対称の構成では、結果を確認して使用してください。

<a id="animation-tools"></a>
## 入力式・タイミング・相対編集

### 入力式（KeyMath）

選択キーフレームの**フレーム位置**と**値**を数式で変更できます。フレーム／値を個別に有効化し、入力欄へ式を記入して適用します。対応する元エディターでは、選択マーカーやNLAストリップの時間編集にも使用できます。

| 変数・関数 | 内容 |
| --- | --- |
| `frame` / `value` | 処理中のフレーム位置／値 |
| `auto` | 対象のON/OFFに応じてフレーム・値・その組を返す |
| `pivot` / `i` | 基準値／処理順番号 |
| `time_i` / `time_n` | 対象内の順番／個数 |
| `time_gi` / `time_gn` | 選択全体での順番／総数 |
| `obj_i` / `obj_sel_i` | オブジェクト順／選択順 |
| `obj_start` / `obj_end` | オブジェクト内の選択時間範囲 |
| `curve_start` / `curve_end` | カーブ内の選択時間範囲 |
| `sel_start` / `sel_end` | 選択全体の時間範囲 |
| `t_sel` / `t_obj` / `t_curve` | 各範囲での正規化時間位置 |
| `rand()` / `randf(a,b,...)` | 乱数／指定範囲の乱数 |
| `hash_u32(...)` / `hash01(...)` | 安定ハッシュ |
| `clamp` / `lerp` / `remap` / `smoothstep` | 制限・補間・範囲変換 |
| `sin` / `cos` / `sqrt` / `floor` / `ceil` など | 数学関数 |

ほかに、前後キーのフレーム・値、キー間の差、選択範囲の最小・最大値、マテリアル、マーカー、NLAストリップの情報などがあります。UIの **変数・関数一覧** から詳しいリファレンスを開けます。

#### 入力式の例

| 目的 | 対象 | 式 |
| --- | --- | --- |
| 選択順に5フレームずつずらす | フレーム | `frame + obj_sel_i * 5` |
| オブジェクトごとに時間をランダムにずらす | フレーム | `frame + randf(-8, 8, 'obj')` |
| オブジェクトごとに一定のランダム値を加える | 値 | `value + randf(-0.2, 0.2, 'obj')` |
| キーごとに異なるランダム値を加える | 値 | `value + randf(-0.1, 0.1, 'key')` |
| カーブごとに値の倍率を変える | 値 | `value * (0.8 + rand('curve') * 0.4)` |
| 選択範囲に波状の変化を加える | 値 | `value + sin(t_curve * tau) * 0.2` |

乱数はスコープとシードを使って制御できます。お気に入り式は登録・編集・削除・JSON入出力ができ、プリファレンス側へ保存されます。式は適用時の値を基準に評価するため、繰り返し適用すると編集が重なります。

### タイミング調整

オブジェクトの選択順などを使った時間差の作成、開始位置・終了位置の整列に対応します。入力式と組み合わせることで、連続した動きやランダムな開始タイミングを作成できます。

### 相対編集

現在の変化量を既存のキーへ反映し、アニメーションの形を保ちながら位置や値を調整するための機能です。**選択キーのみ**のアイコンで対象を絞り込めます。

相対編集は **自動キー入力をOFF** にして使用します。Studioでは自動キー入力がONの間、相対編集の切り替えが無効になります。

### グラフ表示フィルター

移動・回転・スケールとX・Y・Zを、アイコンボタンで複数選択できます。種類・軸をすべてOFFにした場合は、それらによる限定を解除します。選択対象が変わった場合も設定した条件に追従します。

「選択のみ」は対象の絞り込みに使います。グラフ上のキーをドラッグするためにキー選択が変化しただけで、対象カーブが消えないように処理しています。

### ループカーブ

繰り返し、オフセット付き繰り返し、ミラーなどの設定でカーブをループさせます。Studioからはグラフエディターを表示していない場合も、対象を解決できれば操作できます。**Alt＋クリック**でループを削除します。

### 回転モード変換

選択オブジェクト／ポーズボーンの回転を、Euler各順序、Quaternion、Axis Angleへ変換します。アニメーションの保持方法を選択できます。

| モード | 内容 |
| --- | --- |
| 既存キーのみ | 元のキー位置を変換。キー間の補間は一致しない場合があります。 |
| カーブ近似 | 毎フレームの見た目をサンプルし、元のキー位置を使って近似。 |
| 高精度カーブ近似 | 誤差の大きい区間に中間キーを追加。近似精度を調整可能。 |
| 毎フレーム焼き込み | 回転キー範囲を毎フレームサンプルしてキーを作成。 |

<a id="curve-editor"></a>
## Curve Editor

選択したFカーブのキーフレームへ、編集したイージングを適用します。オブジェクトだけでなく、シェイプキー、マテリアル・ノードなどの対応するFカーブも対象になります。

### 基本の使い方

1. グラフエディターなどで、対象のキーを2つ以上選択します。
2. Curve Editorを開きます。
3. ベジェを編集するか、プリセットを選択します。
4. 適用範囲を選び、**適用**を実行します。

**コピー**では選択キーの曲線を読み込みます。起動元のエディターに表示される編集可能なカーブを参照し、候補が複数ある場合はアクティブカーブを優先します。内側のキーはベジェの中間点として取り込みます。

### 編集モードと操作

| 機能 | 内容 |
| --- | --- |
| ベジェ | ハンドルと中間点を使ってイージング曲線を編集 |
| ダイナミック | BlenderのElastic／Back補間、イージング方向、振幅・周期を設定 |
| サンプルキー | 曲線をサンプルした線形キーへ変換し、キー数を調整 |
| 各区間へ適用 | 隣り合う選択キーの区間ごとに、同じ曲線を適用 |
| 範囲へ適用 | 最初から最後の選択キーまでを1つの範囲として適用。内側のキー配置が変わります |
| スムーズ | 選択範囲の内側へ向いたベジェハンドルを少しずつ滑らかに調整 |
| 反転 | 編集中のイージング曲線を反転 |
| リセット | 編集中の曲線を直線へ戻す |
| グリッドの表示リセット | グリッドのズーム・移動を初期状態へ戻す |
| スナップ | ドラッグ中の点を0.1間隔のグリッドへスナップ |

曲線自体の「リセット」と、グリッドの表示リセットは別の操作です。

| グリッド操作 | 動作 |
| --- | --- |
| ハンドル・点をドラッグ | 曲線を編集 |
| Ctrl＋クリック | その位置でベジェを分割し、中間点を追加 |
| 中間点をCtrl＋クリック／右クリック | 中間点を削除 |
| 中ボタンドラッグ | 表示を移動 |
| ホイール | 拡大・縮小 |
| Ctrl＋Z／Ctrl＋Shift＋Z | ツール内のUndo／Redo |

グリッド下部に操作ヒントを表示します。曲線やグリッド自体にはホバーポップアップを出さず、ボタンのヒントを表示します。

### プリセット

内蔵イージングとユーザープリセットを利用できます。プリセット欄は初期状態で閉じており、グリッド右側の半透明ボタンで開閉します。グリッド／リスト表示、スクロール、現在の曲線の追加、ユーザープリセットの削除に対応します。内蔵プリセットは削除しません。

グリッド上の表示リセット・スナップ・プリセット開閉ボタンは半透明で表示されます。

<a id="rig-picker"></a>
## Rig Picker

キャラクターごとの操作盤を作成します。ボーン・オブジェクトの選択、記録した値の適用、プロパティの直接調整などをボタンへまとめられます。

### 作成できる項目

| 種類 | 用途 |
| --- | --- |
| シェイプボタン | プリセット形状を使った選択・登録操作 |
| 画像ボタン | 任意画像を使った選択・登録操作 |
| スライダーボタン | ドラッグで登録値やポーズの適用量を調整 |
| 2D移動ボタン | 2次元の位置に応じて登録した値・トランスフォームを補間 |
| コメント | 説明文、部位名、操作グループの見出し |
| タブ | キャラクター・部位・用途ごとにレイアウトを整理 |

右クリックメニューは **ボタンを作成 → リグセットを作成 → コメントを作成 → タブを作成** の順に配置しています。コメント・タブはそれぞれ専用コマンドから作成します。

左側の半透明ボタンを開くとシェイプのプリセット一覧が表示されます。形状をドラッグ＆ドロップして、ピッカー上へ追加できます。

### ボタンの編集・登録

ボタンを右クリックして、種類、名前、画像、色、配置、登録対象を編集します。シェイプ／画像／スライダー／2D移動の種類を後から変更できます。

Blenderのオブジェクトや数値欄の右クリックメニューから、選択・トランスフォーム・プロパティを登録できます。対応メニューでは、登録と同時にピッカーボタンを作成することもできます。

- ボーン選択では対象アーマチュアを選択し、必要に応じてポーズモードへ切り替えます。
- シェイプ・2D移動ボタンにも画像を設定できます。
- ボタンのカラーは塗りと線の共通設定です。
- スライダーのゲージは、ボタン本体と区別できる色で表示します。

### スライダーボタン

**ポーズライブラリの適用量**、**登録した数値の補間**、**対象プロパティの直接調整**に使用できます。0〜1以外の範囲も設定できます。

登録値を補間する方式では端点とその値を指定します。直接調整では対象プロパティそのものの値を操作し、回転などはプロパティの単位を考慮した表示になります。

シェイプキー、オブジェクト／ボーンの移動・回転・スケール、数値カスタムプロパティなどを登録できます。整数・真偽値はそれぞれの型に合わせて処理します。文字列や実行コマンドは連続補間の対象ではありません。

1つのボタンへ複数の登録値を追加できます。右クリック編集の **登録値を追加** では、対象とデータパスを指定して現在値を取得できます。

### 2D移動・加算・ポーズとの合成

2D移動ボタンは、複数の位置で登録した状態を補間します。異なる位置に値を登録して操作範囲を作成してください。

**現在の値に加算**を有効にすると、ドラッグ開始時の値を基準に、操作による差分を加えます。たとえば登録値が0〜10、開始位置が0、現在値が30なら、半分までドラッグした結果は35になります。同じ位置を再評価するだけで加算が積み重なる方式ではありません。

2D移動のトランスフォームは、他の対応ボタンや通常モードのポーズライブラリと合成する設定もあります。これはローカルの変換を合成する機能で、任意プロパティやリグ制約のすべてを同じ方式で合成するものではありません。

### コメントとタブ

コメントは白い文字を基本として、文字に合わせた小さい範囲で作成します。右クリックから文字、サイズ、文字色、背景色・背景サイズなどを編集できます。

コメント右上のロックアイコンをクリックすると、コメント全体を選択できるか切り替えられます。ロック中でもロックアイコン自体は操作できます。コメントはボタンと同様に削除できます。

タブはタブ列の右側にある小さな **＋** から追加でき、右クリックで名前などを編集できます。各タブの拡大率・表示位置を個別に保持します。

### 主な操作

| 操作 | 動作 |
| --- | --- |
| G／R／S | 選択した項目の配置を移動／回転／スケール |
| S操作中の中クリック | ローカル軸へのスケール固定／解除 |
| S操作中のX／Y | ローカル軸を指定。同じキーで解除 |
| 左クリック／Enter | 配置操作を確定 |
| Esc／右クリック | 操作を取り消し |
| 中ボタンドラッグ／ホイール | ピッカー表示の移動／拡大・縮小 |
| スライダーを左右ドラッグ | 値を調整 |
| スライダードラッグ中のShift | 微調整 |
| Ctrl＋Z／Ctrl＋Shift＋Z | 対応する配置・値操作のUndo／Redo |

ボタン配置と、ボタンに登録したリグ・プロパティの操作は別の処理です。ドラッグ確定時のキー挿入オプション、または自動キー入力が有効な場合、対応する値操作の確定時にキーを挿入します。

<a id="rig-templates"></a>
## Rigify・Auto-Rig Pro連携

生成済みの人型リグから、全体が人型になるピッカーの基本セットを作成できます。

1. 対象リグを選択します。
2. ピッカーの右クリックから **リグセットを作成** を実行します。
3. 自動判定またはリグ種類を指定し、操作用リグを確認します。
4. 指やIK/FK設定など、追加する項目を選んで作成します。

実際に存在するボーン・設定だけを新しいタブへ追加します。元のリグを生成したり、存在しないプロパティを追加したりする機能ではありません。再実行しても既存タブを自動で置き換えません。

### Rigify

全体、腰、胸、首、頭、肩、腕・脚、指、IKコントローラー、ポールなどを配置します。対応リグではIK/FK、ストレッチ、追従、首・頭の設定を追加します。

**FK→IK／IK→FKスナップ**で姿勢を合わせて切り替えます。値だけを変更するIK/FKボタンとは用途が異なります。生成リグのUIに登録されたスナップ処理を使用するため、そのリグのUI処理が利用できる必要があります。

### Auto-Rig Pro

FKとIKで共通の人型ボタンを使用し、現在の切り替え状態に応じて対応ハンドルを選択します。IK/FKスナップ後は切り替え先のハンドルへ選択を引き継ぎます。

| 部位 | 対応する設定の例 |
| --- | --- |
| 腕・手 | IK/FK、長さ、ストレッチ、腕のねじり・固定、肘ピン、ポール、指の握り込み |
| 脚・足 | IK/FK、長さ、ストレッチ、太もものねじり・固定、膝ピン、ポール、足ロール |
| 対応リグの追加設定 | 3ボーンIK、硬さ、足ロールの切り替え・展開、Child Ofの親切替など |

スナップはAuto-Rig Pro側の登録済み処理を呼び出します。**Auto-Rig ProまたはRig Toolsを別途有効にしてください。** 製品本体は同梱していません。

Quick Rigで元骨格と操作用リグが分かれている場合は関連情報から操作用リグを探します。候補を特定できない場合は、生成済みの操作用アーマチュアを直接指定してください。独自に全面改名されたリグや追加肢などは、作成後の調整が必要になる場合があります。

<a id="transform-tools"></a>
## 変換ツール

StudioとTPASのNパネルに、**コピー／ピン／一時ピボット**を中心とした3段のUIを用意しています。各段の詳細ボタンは、下側に設定を展開する折り畳み式です。

### コピー・貼り付け

オブジェクト／ポーズボーンのトランスフォームを記録して貼り付けます。

- グローバルと基準に対する相対変換。
- 移動・回転・スケール、各XYZの対象マスク。
- 現在フレームとフレーム範囲のコピー・貼り付け。
- コピー履歴、貼り付け時のキー挿入。
- 選択キー、再生範囲、カスタム範囲を使った範囲指定。

範囲コピーは評価した変換の記録です。元のFカーブのハンドルや制約構成を丸ごと複製する機能ではありません。

### ピン・一時ピボット

グローバル／相対／カーソルなどを基準に、対象の姿勢を保持しながら調整します。確定、キャンセル、ベイクを使い分けられます。

一時ピボットではカーソルを利用して変換の基準を作成します。ライブ操作の状態は一時的なもので、ファイル読み込みやUndoなどで終了します。

### 3Dカーソル操作

アクティブ要素や選択中心などから位置・向きを取得し、カーソル用の移動・回転ギズモ、数値オフセット、リセットを使用できます。ボーンの頭・末尾・中心など、対象に応じた取得にも対応します。

### 親切替

専用のChild Of制約を使って、姿勢を維持する親切替を作成します。親の切り替え境界への移動、前後の姿勢への接続、ベイクに対応します。

TPASが管理する制約を対象とする処理です。通常の親子関係や、任意に作成したすべての制約を一括で置き換えるものではありません。複雑な制約・IK・ゼロスケールなどがある場合は、評価結果を確認してください。

<a id="pose-library"></a>
## ポーズライブラリ

Sakura PoseLibをベースに、**TPAS → ポーズライブラリ**でポーズを管理します。

- ポーズブックによる分類。
- ポーズの追加・置換・コピー・統合・適用。
- 複数ポーズの適用量を使った合成。
- **選択ボーンのみ登録**による部分ポーズの作成。
- ポーズに含まれるボーンの選択。
- 通常モードとアニメーションモード。
- JSON／CSV／VPD形式などの入出力。
- リグピッカーのスライダーボタンとの連携。

「選択ボーンのみ登録」がONでボーン選択がない場合は、空のポーズを作成せず中止します。

通常モードではポーズの変換値を直接扱い、アニメーションモードではAction制約と適用量を利用します。モードを切り替えるだけで既存キーが自動変換されるわけではありません。MMD関連の機能には、別途mmd_toolsなどが必要になる場合があります。

ポーズブックはアーマチュアオブジェクトのデータとして.blendへ保存されます。

<a id="property-pins"></a>
## 登録プロパティ・選択の登録

よく使用する数値欄や選択対象を、**登録プロパティ**へまとめます。

1. Blenderの対応するプロパティ欄を右クリックします。
2. **TPASのNパネルにプロパティを登録** を実行します。
3. TPASのNパネル、またはAnimation Studioの登録プロパティ枠から操作します。

元の値への参照を登録するため、ここでの編集は元のプロパティへ直接反映されます。Studioでもドラッグやクリック入力で調整でき、小数精度や角度の単位を考慮して表示します。

オブジェクトなどの右クリックから **TPASのNパネルに選択を登録** も使用できます。複数の操作対象へ素早く切り替えたい場合に便利です。登録項目の整理・削除にも対応します。

<a id="motion-path"></a>
## モーションパス

オブジェクトやボーンの動きを3Dビューポート上の軌跡で確認し、対応するキー・ハンドルを編集します。

- 軌跡の開始／停止、フレーム番号、整数フレーム点の表示。
- 現在フレーム前後、シーン／プレビュー範囲、任意範囲の表示。
- 軌跡上でのキーやハンドルの操作、挿入チャンネルの指定。
- 移動・回転・スケールに関する対応編集モード。
- 軌跡の**ピン止め**による編集前後の比較。
- ピンごとの表示切り替え、削除、全削除、透明度設定。

3Dビューポートのヘッダー、TPASパネル、Animation Studioから操作できます。軌跡が見えない場合は、3Dビューポートのオーバーレイ表示と対象・フレーム範囲を確認してください。

<a id="onion-skin"></a>
## オニオンスキン

前後のフレームの形状を残像として重ね、動きやシルエットを確認します。

- オブジェクトごとの表示対象管理。
- 前／後フレーム数と間隔。
- キーフレームのみ、指定フレーム範囲のみの表示。
- 前後の色、透明度の減衰、X-Ray、ワイヤーフレーム、Fresnel表示。
- 子オブジェクトを含めた表示。
- 特定時点を固定表示するゴーストの追加・表示切り替え・削除。
- 表示設定のプリセット。

TPASのNパネルで詳細を設定し、Studioのショートカットからも操作できます。対象数、形状の重さ、表示するフレーム数によって評価・描画負荷が変わります。

<a id="drivers"></a>
## ドライバー作成

Easy Driverをベースに、**動かす元の最小・最大状態**と**連動先の状態**を記録してドライバーを作成します。

| 項目 | 内容 |
| --- | --- |
| 入力元 | オブジェクト／ボーンの変換、シェイプキー、カスタムプロパティ、対応するデータパス |
| 出力先 | 記録したポーズ、シェイプキー、カスタムパス |
| 記録・調整 | 最小／最大状態の記録、値域・軸・空間の指定、微調整 |

基本手順は **入力元を設定 → 最小・最大を記録 → 出力先を記録 → ドライバーを作成** です。TPASのNパネルで設定します。

<a id="wiggle-bones"></a>
## 揺れものボーン

Wiggle Bonesをベースに、ボーンへ二次的な揺れを付けます。シーン、アーマチュア、ボーン単位で有効状態を管理できます。

- 頭側／末尾側の物理設定。
- 質量、硬さ、伸縮、減衰、重力、風。

- 半径、摩擦、反発、粘着、チェーン設定。
- ピン対象、ソルバー、フルボーン衝突。

<a id="time-and-snap"></a>
## 時間表示・スナップ

### 秒数・BPM表示

ToPu Time Scale Displayを統合し、タイムラインの時間目盛りと3Dビューポートの秒表示を追加します。

- 秒数の主目盛り・サブ目盛り。
- BPM、拍・小節の表示、拍の細分化。
- エリアごとの上側／下側配置。
- 目盛り・文字の位置、サイズ、色、表示密度。
- 設定の保存・入出力。

表示の有効／無効はプリファレンスの **UI表示 → 時間表示** から設定できます。

### アニメーションスナップ

タイムライン操作、キーフレーム操作、フレーム送りに対するスナップを設定します。操作の種類ごとにスナップ対象を分けて設定できます。

**BPMおよび時間のサブ目盛り**へのスナップにも対応し、現在のエディターの目盛り設定を参照します。

| 操作・設定 | 内容 |
| --- | --- |
| Alt | 既定のスナップ修飾キー。設定でShiftへ変更可能 |
| Alt＋ホイール | 既定のスナップ送り。キーマップ変更に対応 |
| Ctrl＋Alt＋A | スナップ設定ポップアップ |
| 標準Frame Offsetの無効化 | Blender標準のAlt＋ホイールとの競合を調整 |

<a id="frame-rate"></a>
## フレームレート変更

FPSプリセットまたはカスタム値を選択し、**変換**と**決定**を使い分けます。

| ボタン | 動作 |
| --- | --- |
| 変換 | キーなどのフレーム位置を新旧FPSの比率で拡縮し、再生時間を維持するようFPSを変更 |
| 決定 | キーなどを移動せず、操作元シーンのFPSのみ変更 |

StudioではFPS指定とボタンを同じ段に配置し、指定値が現在のFPSと異なると赤く表示します。プレビュー範囲・開始・終了フレームも同じ周辺から調整できます。

**変換は選択キーだけを対象にする操作ではありません。** オプションに応じて、次のデータを処理します。

| 対象 | 範囲 |
| --- | --- |
| キーフレーム | ファイル内の全アクション |
| マーカー | 全シーン・全アクション |
| アクションの手動フレーム範囲 | 対応するアクション |
| FPS・シーンの再生範囲 | 操作元シーン |

サブフレームを保持する設定があります。OFFの場合は、キーとハンドルのフレームを整数へ切り捨てます。NLA・音声・物理キャッシュなど、上記以外の時間依存データまで一括変換する機能としては扱わないでください。

フレームレート変更のヘッダーUIは、プリファレンスで表示を切り替えられます。初期状態では非表示です。

<a id="retime"></a>
## マーカー変更・疑似マーカー

タイムラインに専用の基準線を置き、線を動かしてアニメーションの時間配分を変更します。通常のBlenderマーカーとは別の**疑似マーカー**を使用し、マーカーレイヤー機能は使用しません。

1. Studioまたはヘッダーの **マーカー変更** を有効にします。
2. タイムラインの必要な位置で **Shift＋クリック** し、基準線を追加します。
3. 線をドラッグして時間を調整します。
4. 不要な線は **Ctrl＋クリック** で削除します。

通常の空白クリックだけでは追加しません。線はタイムラインに垂直に描画されます。ドラッグはEsc／右クリックで取り消せます。隣の基準点を越える移動は制限されます。

設定に応じてキーやNLAストリップの時間を調整し、後続の基準点を連動させることもできます。通常のマーカーを増やさず、区間ごとのテンポを調整したい場合に使用します。

| Curve Editor | 620 × 560 |
| Rig Picker | 600 × 720 |

サイズ設定は新しい専用ウィンドウを開くときに適用します。実際の外枠サイズや配置は、OS・DPI・画面範囲の影響を受けます。

<a id="storage"></a>
## 保存・データの持ち運び

| データ | 主な保存先・扱い |
| --- | --- |
| リグピッカーのタブ・ボタン・コメント・登録先 | 現在の.blend内のTextデータ `TPAS_RigPicker.json` |
| ピッカーの画像 | 読み込める画像は.blend内へのパック処理に対応。見つからない画像は参照先を確認 |
| ポーズライブラリ | アーマチュアオブジェクトのポーズブックデータ |
| 登録プロパティ・登録した選択 | シーンの登録データ |
| 疑似マーカー | シーンの専用データ |
| 変換ツールの設定・コピー履歴 | シーンのデータ |
| 言語・UI表示・起動サイズ・お気に入り式 | アドオンプリファレンス |
| カーブなどのユーザープリセット | 各機能のプリセット保存先 |
| 実行中のドラッグ・ライブピンなど | 一時的な実行状態 |

**編集後はCtrl＋Sで.blendを保存してください。** UI上で変更しただけでは、ディスク上の.blend保存は完了していません。プリファレンスを保持するにはBlenderのプリファレンス保存も必要です。

新しい.blendにピッカーデータがない場合は空の状態から始まります。昔の外部JSONを自動で読み込むことはありません。別ファイルからレイアウトを移す場合は、ピッカーのインポート／エクスポートを使用します。

JSONでレイアウトを渡す場合、画像などの外部ファイルも確認してください。また、登録先のオブジェクト・ボーン・プロパティを削除または改名した場合は、参照先の修正が必要になることがあります。

<a id="faq"></a>
## よくある質問

### 単体版も一緒に有効にできますか？

統合元と同じクラス・オペレーターを使用する機能があります。競合する単体版は無効にして使用してください。RigifyやAuto-Rig Proなど、連携先として必要なアドオンは別です。

### ヘッダーにボタンがありません

プリファレンスの **UI表示** で、該当エディターの起動ボタンと機能の表示を確認してください。エリアの種類やモードによっても表示内容が変わります。

### Studioでボタンが無効になっています

対象となる3Dビューポート、アニメーションエディター、オブジェクト、アーマチュア、選択キーなどが必要な操作があります。元の編集エリアと選択状態を確認してください。相対編集は自動キー入力がOFFの場合に使用します。

### カーブを適用できません

対象のFカーブで2つ以上のキーを選択してください。起動元のエディターのフィルター、アクティブカーブ、編集可能な状態も確認してください。

### リグセットに一致するボーンが見つかりません

メタリグや変形用骨格ではなく、生成済みの操作用リグを指定してください。Quick Rigで複数のアーマチュアがある場合は、操作用リグを直接選択すると対象を明確にできます。

### IK/FKスナップが動きません

Rigifyでは生成リグのUI処理、Auto-Rig ProではAuto-Rig Pro／Rig Toolsの対応オペレーターが必要です。単にIK/FK値を変更するボタンと、姿勢を合わせるスナップは別の操作です。

### ピッカーが別の.blendでは空になります

ファイルごとに保存する仕様です。共有したい場合はレイアウトをエクスポートし、別ファイルでインポートしてください。

### Undo／Redoは使えますか？

Curve EditorとRig Pickerにはツール内の履歴があり、Ctrl＋Z／Ctrl＋Shift＋Zで対応操作を戻せます。Blenderデータへ適用する操作は各オペレーターのUndoにも従います。ツール内の表示・レイアウト履歴と、Blender全体の履歴は同一ではありません。

### 対応環境について

パッケージはBlender 5.1.0以降を最低要件として指定しています。すべての将来バージョン、OS、GPU、独自リグ構成での動作を保証するものではありません。不具合報告にはBlenderのバージョン、OS、表示モード、再現手順、エラー全文を添えてください。

## コード構成

機能別の処理と、専用画面・設定などの共通処理を分離しています。

| 場所 | 役割 |
| --- | --- |
| `features/animation/` | 入力式、相対編集、ループ、表示フィルター、疑似マーカー、回転モード変換 |
| `features/curve/` | カーブ編集と適用 |
| `features/picker/` | ピッカー、ボタン、リグ連携、レイアウト |
| `features/transform/` | 変換コピー、ピン、カーソル、親切替 |
| `features/poselib/` | ポーズライブラリ |
| `features/property_pins/` | 登録プロパティ・選択 |
| `features/motion_path/` | 軌跡の評価・描画・編集 |
| `features/onion/` | オニオンスキン |
| `features/driver/` | ドライバー作成 |
| `features/wiggle/` | 揺れもの |
| `features/scale/` | 時間・BPM表示 |
| `features/snap/` | アニメーションスナップ |
| `features/remap/` | FPS変換 |
| `studio/` | StudioのUI、描画、入力、操作元コンテキスト |
| ルートの共通モジュール | 登録・解除、翻訳、プリファレンス、表示管理、ウィンドウサイズ、ヒント、数値表示、履歴など |

v0.1.85ではモーションパスの隣接キー探索を共通化し、参照経路を確認できなかった旧ヘルパーを整理しています。ユーザーデータや登録済みレイアウトの形式を変更するための更新ではありません。
